Buy checks

Have a code? The website gives you a pass with its checks and signs Unfret in with it.

Have an invite or intro code?

An invite adds 3 checks, an intro code a few, to a new wallet or a new Unfret pass, one that never had checks.

Backup code of this pass

Unfret made this pass for you when you installed it. If you add checks to it, save this backup code somewhere safe: it gets you a new pass with the same checks if this browser ever loses it.

Use an Unfret pass instead

An Unfret pass is an alternative to a wallet: buy checks for it with a card, SOL or USDC on the checkout page and paste it here. It is kept only in this browser.

Privacy

Unfret reads a page only when you click "Check this page". It then sends the product facts and the page's visible product text (without account menus, your addresses or forms) to the Unfret server. It stores only your sign-in session or Unfret pass, your consent and these settings in your browser, and no analysis history. A page is shared for review only when you report a result as wrong and agree. A result becomes a public link only when you share it and confirm what the preview shows; that link names no account.
